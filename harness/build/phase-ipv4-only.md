# 独立纯 IPv4 版本

用户授权：2026-10-17，新增自用和公开两版，本机到目标/节点限定 IPv4，保留原分流。

实现：独立 `releases/v14.3-ipv4-only/`，不覆盖原版七入口。共用生成器与纯 IPv4 适配源码，provider 刷新强制地址族、完整 DNS 过滤、活动 IPv6 hosts 清除、字面量 IPv6 拒绝。每份 JS 保持 128 KiB 导入预算。

验证：每版静态 67 项、真实 QuickJS/Boa 132 项、隔离核心 120 项；七入口个人/公开差异只允许原有个人例外。显式 hosts AAAA 绕过反例已修复，失败记录保留。新 ZIP 逐成员 SHA256、CRC、解压再生成和静态回放。

边界：全机 IPv4 需要 App/物理网卡阻止旁路 IPv6 和 IPv4 系统 DNS；Shadowrocket 需要额外节点 IPv4 限制。IPv6 阳性回环对照受 EACCES 阻止。未操作运行客户端，未验收真实 TUN、媒体、手机/Mac，后续用户已授权发布独立预发布标签 v14.3.0-ipv4-only-rc.1，原版本保留。
