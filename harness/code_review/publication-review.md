# 发布审阅

| 项目 | 实施 |
|---|---|
| 公开范围 | 独立目录与独立 Git，无个人目标例外、真实节点、订阅或运行凭证 |
| 固定字节 | Git 不转换行尾，上游固定输入保留空白；来源与输出按 SHA256 核对 |
| 暂存区检查 | 扫描真实索引 blob；回归覆盖暂存秘密与工作区清除不同步、空索引、禁止路径和 ZIP 越界成员 |
| 来源许可 | 规则锁、GPL 原文、客户端源码片段原许可和转换说明一同保留，所有 ZIP 附声明与来源 |
| 复现 | 公开固定输入齐全，根历史档案明确跳过；全新解压重跑生成/静态 |
| 验收范围 | 已有核心证据按源码绑定；原生设备、公网 IPv6、浏览器、长时运行另验 |

实际命令和结果见 [build-log](../build-log.md)。
