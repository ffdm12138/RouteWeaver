# 新增纯 IPv4 版本合同

2026-10-17 用户明确授权：在当前自用版和公开 release 版旁，分别新增本机纯 IPv4 的版本。直连到目标和连接代理服务器都限定 IPv4；代理服务器到目标的选择不在控制范围内。

本合同仅适用于 `ipv4-only-r1`。它明确覆盖原版要求保留本机双栈的部分；原版入口、自动模式合同和历史验收不改变。公司归组、DNS 跟组、UDP 防回落、公共组手动选择、业务 DIRECT、国内域名例外与固定远程来源延续各自原版。

IPv6-only 节点与目标失败，不推断对应 IPv4、不自动更换节点、不转 DIRECT。显式节点 IPv6 地址族也强制覆盖为 IPv4，provider 刷新须维持此限制。活动 hosts 不允许提供 IPv6，系统 hosts 不读取。局域网系统 DNS 保留原行为；要满足全机纯 IPv4，用户必须提供 IPv4 系统 DNS 或配置 `x-routeweaver.ipv4-lan-dns`，并由 App/网卡阻止 VPN 外 IPv6。

Shadowrocket 的本机到节点地址族不能仅由 conf 保证，必须额外固定节点为 IPv4。静态、真实 JS 引擎、本机核心、全机 TUN/VPN 和外部设备分别验收；配置交付不等于设备已部署。
