# V14.2 域名内嵌与最新来源审核

日期：2026-10-12。修订：`embedded-domain-r1`，上一修订 `apple-inline-r1`。用户要求完整已审核业务/国内域名进入独立 JS，保留远程补充，并复审最新上游表。状态：`EMBEDDED_DOMAIN_SOURCE_LOCAL_CORE_PASS_DEVICE_PENDING`。没有替换运行中的客户端。

## 变化

Windows/Android JS 内嵌现用域名分类器，总计 115,438 条规则记录，其中 CN 主表 111,595 条后缀；已有 OpenAI、Anthropic、Google、Microsoft、公共基础服务核心和其他业务种子继续内嵌。记录包含重叠、精确名、后缀和既有正则，不能当成独立网站数量或全部互联网覆盖。

内嵌 provider 紧邻其原远程表之前，保持原路由优先级；远程业务新增成员继续经同组 DNS。现有完整缓存时分组语义不变，远程表为空时保住已审核基线。国内网站默认 DIRECT、两公共组手动节点、主动 DIRECT、UDP 不支持拒绝和断节点不回落均保留。国内未知 DNS/UDP 仍经漏网之鱼，按第 11 条合同，不随国内 TCP 自动直连。DNS 上游、IPv6、Fake-IP、下载出口未改。

JS 不读取本地 JSON；内嵌快照和来源维护分别由 `tools/build-embedded-domains.cjs`、`tools/sync-reviewed-data.cjs` 完成。远程 IP-only 表继续保留，未知流量仍代理或拒绝。原生 iOS 同步完整精确/后缀候选，非有限正则仍保留既有审核边界，未擅自扩大匹配。

- [blackmatrix7 提交 83f3712](https://github.com/blackmatrix7/ios_rule_script/commit/83f37120c155f67c8eef43221dabe15cc3c95fec)，提交时间 2026-10-09 22:09:47 UTC，与上一轮相同。

核对 45 份现用来源及 7 份公司核心输入，共 52 份候选。现用 45 份分类器没有规则集合增删，部分注释/行序改变；为保留历史审核绑定，等价分类器保留已审核原始字节与行序，运行原始文件和 URL 升到新固定提交。微软输入唯一新增 `DOMAIN-SUFFIX,cafe.github.com`，被已有 `DOMAIN-SUFFIX,github.com` 覆盖。两个名字的三端 TCP/UDP/DNS 均为微软生态，分流差异为零。没有删除导致代理降到国内 DIRECT，也没有新增宽泛共享云后缀。

原始文件 SHA256、分类器 SHA256、MRS 核心解码哈希和增删详情在 `data/rules/embedded-source-review.json`，内嵌快照绑定同一来源锁。最新指本次取得提交，后续上游内容仍需候选审核后更新固定来源和 JS；刷新固定 URL 不会自动采用未经审核的分支内容。规则项目收录不能证明每个域名当前运营归属或存活。

## 边界与交付

用户已反馈上一轮 Apple 修复后 Windows 登录恢复，这是用户烟测结果；本轮没有独立重现浏览器登录，HTTP 541 的具体响应生成原因仍未确定。

52 个历史单标签 LAN 名称仍保留 Mihomo/iOS 源码模型的已声明差异。iOS 完整配置约 6.17 MB、116,974 条规则，原生解析、配置容量及 DNS 组解释未实机验证；远程新增业务名需要同步重生成 Host DNS。Windows TUN、Android VpnService、iOS VPN 接管及公网 IPv6 未设备验收，回环核心通过不能替代这些验收。

上轮 549 份文件及原包按字节归档在项目 `archive/v14.2-before-embedded-domain-r1-20261011/`；旧 Apple/R1–R6 元数据和报告不改写。最终入口：`src/windows/v14.2.js`、`src/android/v14.2-android.js`、`src/ios/v14.2-shadowrocket.conf`。正式包放 `dist/v14.2/`，CRC/成员哈希/独立解压重放以包回执为准。安装与重载由用户执行。
