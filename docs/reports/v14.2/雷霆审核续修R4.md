# V14.2 雷霆审核续修 R4

2026-10-10，修订 `thunder-repair-r4`。按用户请求修复最后一处 iOS Azure 异步分组差异，并重新对照 [十一条最终需求](../../需求.md) 审核 Windows、Android、iOS。需求原字节不变，45 个固定远程来源及其 90 份原始/分类器字节不变；没有替换运行中的客户端。

本轮源码合同和隔离 Mihomo 核心验证通过。10,395 个有限域名样本零跨端分组差异、零业务 DNS 错配、零业务 UDP/不支持 UDP 错配。**实际 Windows TUN、Android VpnService、Shadowrocket 原生执行和公网 IPv6 尚未验收**，不能据此承诺所有设备、任意域名绝无遗漏或泄漏。

## 两项修复及范围

| 编号 | 证据与原因 | 当前行为 |
|---|---|---|
| R4-01 | `chatgpt-async-webps-prod-eastus-1.webpubsub.azure.com` 在 R3 的 Mihomo 为 OpenAI、iOS 为公共基础服务 | 三端统一精确 Azure 例外，TCP、UDP、DNS 都按 OpenAI 组选择；不支持 UDP 拒绝，主动 DIRECT 保留 |
| R4-02 | 扩大检查发现 Mihomo 的 `\S+` 还接受 `eastus.evil-1`、新地区和未审阅编号；这些名称不足以证明公司租户身份 | 将整个旧启发式收紧为共同的有限精确表；其他 Azure 租户的连接和 DNS 同归公共基础服务，不新增 DIRECT |

共同表为 [Azure 审核表](../../../releases/v14.2/data/rules/azure-async-review.json)，目前包含 eastus 的 **1、17、23** 三个完整名称。1 号是原审核正则已覆盖的目标，也是原差异样本；它是合成路由目标，未证明现仍在用。17、23 号分别有历史首手故障复现记录，仍在原正则范围内，本轮逐个审核纳入精确子集。[历史 17 号报告](https://community.openai.com/t/chatgpt-not-streaming-results/612095/5)、[历史 23 号报告](https://github.com/EFForg/privacybadger/issues/2949)。这些记录不是当前端点存活性、现租户归属或实机连通性证明。

这是明确记录的分类收紧：其他合法数字尾段、地区及子域不会自动沿用旧正则的 OpenAI 归属。公司自有 `chatgpt.com` 下的异步名称仍由自有后缀覆盖。新增 Azure 例外需单独核实归属并审核；使用时可将公共基础服务与 OpenAI 选同一公共组获得共同出口。

采用精确 DOMAIN 和精确 Host DNS，不依赖未验证的原生数字正则或宽泛通配符。Azure 服务提供实例域名，不能把公共后缀整体视为 OpenAI。[Microsoft Azure Web PubSub 文档](https://learn.microsoft.com/en-us/azure/azure-web-pubsub/howto-custom-domain)。原生应用公布了域名匹配及本地 DNS 映射能力；该页面不构成这份配置的原生通过证明。[开发者 App Store 声明](https://apps.apple.com/us/app/shadowrocket/id932747118)。

同步/生成工具写出前验证审核状态、冻结分类器 SHA256、精确表与公司核心/业务表完全一致；篡改、缺失证据、范围扩大或哈希错配会失败，输出保持原字节。旧 OpenAI 快照和 R1–R3 历史报告保留，运行入口不再采用那个 Azure 正则。

全部核心传输终止于自建回环服务，TUN 关闭、合成节点、无真实订阅。精确 DNS 切换实验对同一名称重查前只清理该实验核心的缓存，验证方法使用 Mihomo 公开的缓存接口。[Mihomo 缓存 API](https://wiki.metacubex.one/api/#cachednsflush)。当前回执分别在 `validation/static.json`、`native-routing.json`、`native-dns-egress.json`、`native-selectors.json`、`native-inbound-guard.json`。

首次完整静态运行有 1 项测试程序错误：历史 R3 配置被拿来检查新 R4 生成器的幂等性。修复该历史/当前阶段混用后，完整重跑通过。原失败回执在保存前被成功重跑覆盖；[保留记录](../../../releases/v14.2/validation/inputs/r4-attempts/initial-static.json) 是工具返回结果摘要，明确不是原始完整回执，不把首次运行算作通过。
