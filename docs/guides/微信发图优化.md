# 微信与 QQ 图片分流

适用于 V14.3 主版和纯 IPv4 版。14 个微信、媒体和头像域名后缀使用显式直连规则，其中 `qpic.cn` 覆盖 `gchat.qpic.cn` 等 QQ 图片服务。切换「国内网站」的节点时，这些域名仍直连。 [域名清单](../../releases/v14.3/data/rules/wechat-media.json) · [QQ 图片地址样例](https://github.com/LLOneBot/LuckyLilliaBot/issues/541)

| 客户端 | 微信媒体配置 |
| --- | --- |
| Windows FlClash、Clash Verge Rev | 媒体域名使用系统 DNS 返回真实 IPv4。核心识别到 `Weixin.exe` 或 `WeChat.exe` 时，只为无域名的 IPv4 连接补直连规则。 |
| macOS FlClash | 使用同一套媒体 DNS 和域名规则。无域名的 IPv4 连接按 `WeChat` 进程匹配。 |
| Android FlClash | 使用同一套媒体 DNS 和域名规则。无域名的 IPv4 连接按 `com.tencent.mm` 包名匹配，需要核心收到应用身份。 |
| macOS、iOS Clash Mi、ProjectClash | 使用相同的媒体 DNS 和域名规则。ProjectClash 在支持进程识别的 macOS 使用 `WeChat` 进程规则。 |
| iOS Shadowrocket | 使用原生 `always-real-ip`、`[Host]` 直连 DNS 和域名直连规则。地址族沿用各入口的设置。 |

Mihomo 主版在这批域名的 DNS 上抑制 AAAA、SVCB 和 HTTPS 记录。公司、局域网、外部 DNS 和通用 STUN 规则先于媒体直连例外。IP 连接可从可读的 HTTP Host、TLS SNI 或 QUIC SNI 恢复域名，再命中对应规则。QUIC 识别端口为 UDP/443、8443 和 8000。订阅显式配置的嗅探排除继续生效，旧生成配置中的媒体默认排除会在升级时移除。 [ProjectClash 域名嗅探](https://clash.md/zh/guide/config/sniffer) · [Mihomo DNS 参数](https://wiki.metacubex.one/en/config/dns/#additional-parameters)

在 iOS ProjectClash 的连接对照中，部分无域名 UDP 走「漏网之鱼」时拨号超时，手动切到 DIRECT 后在同一网络观察到同网段的新连接改走直连，用户报告收图恢复。旧生成配置会丢弃嗅探读出的媒体域名。隔离回放复现了这类误分流，并验证微信和 QQ 图片的合成 QUIC 流量命中 DIRECT。完全不带可读域名的连接仍依赖已有分类或「漏网之鱼」。 [两轨传输回执](../../releases/v14.3/validation/domestic-resilience/wechat-media-transport-r1.json)

APNIC 可核对公网地址的登记机构，公开 GeoIP 和腾讯规则表也可核对覆盖范围。确认收图流量身份仍需要可读域名或可核对的服务端点。 [APNIC 腾讯地址登记](https://rdap.apnic.net/ip/109.244.0.0) · [APNIC 腾讯云地址登记](https://rdap.apnic.net/ip/175.27.0.0) · [MetaCubeX GeoIP 目录](https://github.com/MetaCubeX/meta-rules-dat/tree/meta/geo/geoip)

FlClash 可在合并时覆盖 `find-process-mode`。测试字面量连接时，检查最终配置使用 `strict` 或 `always`，并从连接页确认进程和命中规则。Mac 的 `tun.dns-mode` 沿用原配置，避免切换系统 DNS 注册方式后影响局域网和 MagicDNS。 [FlClash 配置合并](https://github.com/chen08209/FlClash/blob/v0.9.3/lib/common/task.dart#L179-L218) · [Mihomo 系统 DNS 问题记录](https://github.com/MetaCubeX/mihomo/issues/3420)

设备验收可在同一网络比较两次未缓存图片的加载时间，同时记录目标域名或 IP、命中规则和出口。新版真实收图、Mac TUN 启动和 Shadowrocket 原生 DNS 待实机测量。 [当前配置回执](../../releases/v14.3/validation/domestic-resilience/wechat-media-sniff-r1.json) · [历史 Windows 进程回执](../../releases/v14.3/validation/domestic-resilience/wechat-process-r1.json)
