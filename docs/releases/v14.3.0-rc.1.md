# RouteWeaver v14.3.0-rc.1

首个公开预发布版本，提供 Windows FlClash/Mihomo、Android Mihomo、iOS Clash Mi、iOS Shadowrocket、macOS FlClash 和 macOS Clash Mi 六个独立入口。公开版保留共同设计需求、国内协议跟组、固定远程规则与小型内嵌基线；个人目标例外不包含在公开源和附件中。

## 下载

在 Assets 中按平台下载对应 JS / conf；需自行保留节点和订阅，并手动选择公共组的可用节点。也可下载：

- `v14.3-deployable.zip`：全平台入口与使用文档。
- `v14.3-macos.zip`：两份 Mac 入口与 Mac 文档。
- `v14.3-audit-evidence.zip`：生成器、固定公开输入、测试和有界证据。
- `package-verification.json` 和 `SHA256SUMS.txt`：包回放范围、逐文件/附件校验。

所有 ZIP 附原始许可、第三方声明与来源。原创代码采用 MIT；上游规则和源码片段保留各自许可。

## 验证范围

生成器核对来源和输出 SHA256；静态合同覆盖完整已审核域名集合、DNS/UDP、幂等、规则下载边界、失败与上游反例。打包验证 CRC、成员 SHA256 和全新解压后的生成/静态回放，公开克隆不依赖外层工作区。

本地全新解压结果：主静态 27 项（三个平台各 233,396 个域名、917 项既有用例），Mac 静态 11 项，小火箭有限源码模型 5 项，均通过。

[发布提交的 Windows / Ubuntu CI](https://github.com/ffdm12138/RouteWeaver/actions/runs/38741427070) 全部通过。14 个远程附件已重新下载并全部匹配 SHA256；未登录读取发布页与下载 Windows 文件也通过核对。

已有隔离 Mihomo 核心回执按公开源码哈希复核；本次公开发版没有重新执行原生核心或设备验收。CI 在 Windows / Ubuntu 重跑来源绑定、生成、静态打包和发布内容扫描。额外根历史档案明确记录 `SKIPPED_HISTORY`。

## 已知限制

Android VPNService、iOS/macOS NetworkExtension、Shadowrocket 原生完整国内 DNS、公网 IPv6、WebRTC、浏览器与长时运行仍需分别验收，因此此版本保持 Pre-release。代理故障或不支持 UDP 不自动回落 DIRECT；冷启动规则下载失败时只保证关键内嵌基线。

Windows FlClash 0.9.0 应在应用 TUN 设置开启“严格路由”，关闭“追加系统 DNS”；Clash Mi 使用返回对象的 JS 并遵照“内置-不覆写”设置。完整步骤见 [README](../../README.md) 和[使用说明](../guides/使用说明.md)。
