# 项目结构

这是独立公开源，不引用外层个人工作区。根 `archive/`、`.work/`、`dist/` 不进入公开 Git；当前复现必需的固定输入在 `releases/v14.3/validation/inputs/`。完整公开克隆可使用 `python tools/verify-v14.3.py --skip-history` 核对当前来源和回执，历史档案明确记为 `SKIPPED_HISTORY`。

`validation/network-review/manifest.json` 引用的 52 份 `.download` 是已固定哈希、供离线来源合同核对的公开原始输入，随 Git 和审核包保留；它们不属于运行客户端的缓存。额外实验与未固定下载仍放 `.work/`。

当前版本由根 CURRENT_RELEASE.json 选择，根 README.md 是使用入口，docs/需求.md 是最终合同。客户端直接导入对应 JS/配置，不引用仓库路径。

| 目录/文件 | 职责 |
|---|---|
| AGENTS.md、GOALS.md、PLANS.md、PROMPTS.md | 工作约定、目标、计划和复用提示 |
| harness/build/、context/、code_review/、build-log.md | 阶段定义、决策上下文、审阅与执行证据 |

| releases/v14.3/src/<platform>/ | 当前独立 Windows、Android、iOS Clash Mi JS、macos/ 下的 FlClash 与 Clash Mi JS，以及自包含 DNS 的 Shadowrocket 精简配置 |
| releases/v14.3/metadata/macos-sources.json、macos-delivery.json | 两份 Mac 生成来源、入口哈希、独立静态/Windows 核心回放与 Mac 实机未验收范围 |
| releases/v14.3/metadata/ios-delivery.json | 当前 iOS 配置/JS 哈希、Clash Mi 设置、核心证据与原生未验收范围 |
| releases/v14.3/metadata/shadowrocket-lean.json | 小火箭生成来源、固定 RULE-SET、业务 DNS 保留与原生完整国内 DNS 边界 |
| releases/v14.3/data/rule-sources.lock.json | 固定来源、格式及原始/有效分类器哈希 |
| releases/v14.3/data/rules/embedded-policy.json | 小型内嵌策略及选择理由 |
| releases/v14.3/data/rules/reviewed/ | 公共完整原文件和离线复验分类器 |
| releases/v14.3/tools/ | 受哈希约束的生成及来源核对 |
| releases/v14.3/tests/、validation/ | 静态/本机核心检查、回执和候选 |
| releases/v14.3/validation/inputs/v14.2-baseline/ | 不可变原版源码/数据，供有限对照，不是客户端运行依赖 |

| docs/ | 当前文档单一正文；reports/<version>/ 保留各阶段原文 |
| dist/<version>/ | 正式部署包、审核包和包校验 |
| .work/ | 自有核心、证书、临时缓存和解压复验 |
| archive/ | 旧版本、原文、旧回执和迁移前根文件 |

V14.2 历史定位由 CURRENT_RELEASE.json 的 legacyRelease 字段记录；本轮修改前的 V14.3 配置、合同和回执在 archive/v14.3-before-domestic-protocol-r1-20261013/ 保持原字节。当前 Shadowrocket 由独立生成器移除完整国内重复表，保留业务 DNS 并按新国内合同调整，入口由 entries.shadowrocket 指定；它不是历史原字节副本，原生验收仍待完成。根目录不新增旧版入口副本。当前文档通过 docs/README.md 查阅；打包工具复制正文并调整包内相对链接。


## IPv6 兼容修订

标准入口由 `CURRENT_RELEASE.json.entries` 指定；手动 IPv4 兼容入口由 `compatibilityEntries` 指定。`releases/v14.3/tools/network-compat*` 提供节点默认值，`ipv4-local-adapter.js` 与 `build-network-compat.cjs` 生成兼容文件；`metadata/network-compat-delivery.json` 绑定模式清单、静态与本机核心回执。根 `tools/network_release.py` 供记录/核对复用；固定输入和旧归档不因此改写。详见 [模式说明](../guides/IPv4兼容模式.md)。

## 无域名 IPv6 核心研究

`releases/v14.3/research/ipv6-direct-fast-fail/` 是独立的源码补丁、GPL-3.0 许可、固定来源与有界证据，不是 `src/` 导入文件。原生编译、重建目录、原始用户日志和实验运行配置只放 `.work/`；研究回执不覆盖现有版本的正式核心回执。
